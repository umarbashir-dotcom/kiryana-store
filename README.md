# Kiryana Store

A full-stack e-commerce application for a Kiryana (grocery) store, built with modern web technologies and real-world authentication, authorization, security, and role-based access control.

## 🚀 Live Demo

**Live URL:** https://kiryana-store-jet.vercel.app

**[Visit Kiryana Store →](https://kiryana-store-jet.vercel.app)**


## ✨ Features

* 🔐 **Authentication & Authorization**

  * User registration and login
  * JWT-based authentication
  * Protected routes and resources
  * Role-based access control

* 📧 **Email OTP Verification**

  * OTP-based email verification
  * Email delivery for authentication-related actions

* 🛡️ **Security**

  * User-based rate limiting
  * Password hashing
  * JWT authentication
  * Backend authorization and protected APIs

* 👤 **Customer Experience**

  * Customer-specific views and permissions
  * Browse and interact with store products
  * Profile and account management

* ⚙️ **Admin Experience**

  * Dedicated admin dashboard
  * Admin-only routes and features
  * Role-based administrative access

* 🌐 **Full-Stack Application**

  * React frontend
  * Node.js and Express.js backend
  * REST API integration
  * MongoDB database
  * Frontend and backend deployed
